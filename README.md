# Todolist App
Todolist App adalah aplikasi menajamen tugas sederhana yang memungkinkan pengguna untuk membuat,mengelola daftar pekerjaan sehari hari. Aplikasi ini dirancang untuk membantu pengguna tetap produktif dengan fitur manambah dan menghapus tugas 

Fitur Utama 
- Menambahkan tugas baru
- Menghapus tugas
